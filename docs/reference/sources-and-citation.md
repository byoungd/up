# 资料、引用与核验说明

这本书不希望读者把任何一句话当成不可质疑的结论。这一页说明三件事：书里的陈述分成哪几类，外部资料多久复核一次，以及怎样引用和更正。

## 三类陈述

**研究结论**来自公开发表的研究、官方指南或规范文档。它描述的是特定样本、材料、测量和条件下得到的结果，不能直接写成对某个人的保证。书中引用时会保留作者、年份、链接和适用边界；能核对的地方给出一手来源，不能用营销页面代替。

**个人经验**只证明作者经历过什么。它可以是证据的一部分，但不是规律：一次失败不能推出所有人都该避免同一条路，一次恢复也不能推出同一种方法对每个人都有效。读个人故事时，请把它当作场景，而不是处方。

**待检验的假设**是作者或读者对未来的推断。它可能正确，也可能被下一次实验推翻。书里会尽量标明“如果……那么……”的条件；没有标明的判断，你可以先当作假设处理。

三类陈述混在一起时，最容易产生“听起来都对、用起来无效”的段落。阅读时可以先问一句：这句话属于哪一类？

## AI 资料的复核规则

AI 产品、模型能力、价格、套餐、协议和供应商政策变化很快。本书按变化速度分级复核：

- **30 天**：使用政策、安全公告、产品功能、地区与套餐。页面会声明 `source_review_interval: 30`。
- **60 天**：协议规范、实现指南和变化较快的工作流。
- **120 天**：相对稳定的概念、研究背景和历史事实。

规则如下：

1. 优先引用官方文档、正式规范或一手公告，不用二手博客代替；
2. 记录核验日期（`sources_checked`），它与正文修改日期（`updated`）分开；
3. 产品入口只是“可以重新核验的页面”，不是当前功能清单，也不是效果保证；
4. 无法再次核验的页面标注为历史资料，不继续当作当前证据；
5. 政策、价格和能力必须回到正式协议、官方页面与实际验收。

如果你发现某条产品描述已经过时，欢迎按下一页的方式报告。

## 如何引用本书

引用时请写明书名、作者、版本、日期和网址，并注明正文采用 CC BY-NC 4.0：

```text
韩先凯. 人生进阶指南：一个普通人的失败、恢复与重新学习. 1.1.0 版. 2026-11-23.
https://byoungd.github.io/up/
```

英文版：

```text
Han Xiankai. Still Here: A Field Guide to Beginning Again. Edition 1.1.0. 23 November 2026.
https://byoungd.github.io/up/en/
```

仓库根目录的 [`CITATION.cff`](https://github.com/byoungd/up/blob/main/CITATION.cff) 提供了机器可读的引用信息。本书没有 DOI，也没有分配 ISBN；请不要自行补上一个。引用具体章节时，可以加上章节标题和页面地址，方便读者回到原文。

## 报告来源错误

如果你发现：

- 引用的研究结论与原文不符；
- 链接失效或指向了另一个页面；
- 产品描述已经过时；
- 中文版与英文版对同一事实的表述不一致；

请通过[问题模板](https://github.com/byoungd/up/issues/new/choose)提交，并写清页面、原句、你认为正确的来源和核验日期。涉及个人信息、未授权图片或安全问题的，不要公开发布，按 `SECURITY.md` 的私有渠道报告。

维护者会先核对来源，再修改正文；只改日期、不核对内容不算完成复核。
