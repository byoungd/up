# Bibliography

This is a selective list of sources the book actually cites. It is not exhaustive. Papers and books are not distributed with the repository; readers reach them through their DOI or official link. Each entry names the chapter where it is used so the context and limits can be checked.

## How to Use This List

- A research finding describes results under its own sample, materials, measures, and conditions. It is not a personal guarantee.
- Official guidance and specifications change. Record the version and access date when citing them.
- When a link fails, the book keeps the original task and looks for the current page from the same source. It does not pile up new links just to keep a count.
