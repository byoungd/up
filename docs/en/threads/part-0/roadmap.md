# Book Roadmap

This book begins with one ordinary person's failure and recovery, then moves into relearning, working with AI, daily practice, and long-term action. You do not have to read it in order, but it helps to see the whole map first.

Directory names such as `part-2` and `part-1` are historical theme slugs, **not reading order**. The book's order is the one in this table and the table of contents: Part I (story and recovery) first, Part II (learning again) second.

## Three Reading Paths

### Story First

For a reader who wants to be understood before being taught.

1. [Prologue](prologue.md) → [My Story](../part-2/my-story.md);
2. [I Am Still Here](../part-2/depression-anxiety-recovery.md) → [Recovery](../part-2/recovery.md);
3. [Decision-Making](../part-2/decision.md) → [Relationships](../part-2/relationships.md);
4. When you have room, enter the [Part II Introduction](../part-1/open-input.md).

### Method First

For a reader who arrives with one concrete task and wants to start quickly.

1. [CEFR Self-check](../part-1/0-cefr.md) → [Learning Principles](../part-1/1-understanding.md);
2. Choose **one** line among vocabulary, grammar, listening, reading, speaking, and writing, and finish one fourteen-day experiment;
3. [Learning Anything with AI](../part-3/1-ai-learning.md) → [Artifacts](../part-3/4-artifacts-and-delivery.md);
4. [First Week Practice](../part-4/week-1.md) → [90-Day Action Plan](../part-5/90-day-plan.md).

### When Capacity Is Small

For a reader whose body or mood does not allow long reading today.

1. Read only the “reduce the load” section of [Recovery](../part-2/recovery.md), and do none of the exercises;
2. Open [Learning State](../../templates/learning-state.md) and write four lines: problem, clues, minimum action, boundary;
3. Stop there. Leave the [Rhythm Ledger](../../templates/rhythm-ledger.md) for tomorrow or next week. Do not do the homework later to catch up.

You can switch paths midway. If a story makes you want to work, move to the method; if the method leaves you depleted, return to recovery. The structure allows travel in both directions.

## If You Have Only Five Minutes Today

If the only opening you have is very small, do not try to start a book:

1. Open [Learning State](../../templates/learning-state.md);
2. Write the one problem that is most real today;
3. Write one minimum action that can be finished **today**;
4. Write one boundary that must hold: privacy, body, relationships, or money.

Those four lines are a beginning. Five minutes do not need to produce a conclusion. They only need to bring the next step out of the fog.

## After You Finish

The appendices follow the main text and are organised by use: check the [Glossary of Terms and Methods](../../reference/glossary.md) first, then enter the [Reading Map](../../reference/reading-map.md) by problem; open the [Toolkit Overview](../../templates/toolkit.md) when you need to do something; consult the [Bibliography](../../reference/bibliography.md) and [Sources, Citation, and Verification](../../reference/sources-and-citation.md) when you want to cite or verify; read [the book case study](../part-5/book-as-proof.md) in the appendices if you want to know how this book itself was made.

If you finish, the trace worth keeping is not “I finished”. It is one real delivery, one retest record, or one decision you are willing to check again in ninety days. Put it in the [90-Day Cycle Map](../../templates/90-day-cycle.md).
