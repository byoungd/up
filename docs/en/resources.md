# Third-party Resources

This directory lists optional external entries for finding tools and materials. It records link availability and how each public page describes itself; it is not a security, privacy, compliance, quality, or pricing audit.

Before sharing API keys, customer records, company secrets, or sensitive personal data, review the provider's data handling and deletion policies.
