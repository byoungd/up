# 这本书适合谁，不适合谁

一本书最重要的承诺，不是它什么都懂，而是它知道自己为谁而写。这一页不推销，只帮你判断：现在翻开它，是否值得你的时间。

## 适合谁

- **想靠自己把一件事学明白的人。** 你不需要报班、等老师或凑齐工具，只需要一个真实任务、一份基线和一个愿意复测的日期。
- **正在从一次中断里回来的人。** 失业、创业失败、身体出问题、关系结束、长时间停滞——书里有一条从恢复走向重新学习的路，而不是一句“振作起来”。
- **在工作中使用 AI，又不想把判断交出去的人。** 你会看到怎样把来源、隐私、验收和责任写进任务，而不是让工具替你决定。
- **正在陪一个孩子学习的家长或老师。** 家庭学习篇把时间、账户、数据边界和“谁做决定”分开，避免把成人的焦虑套在孩子身上。
- **愿意接受“没有统一答案”的读者。** 书里区分研究结论、个人经验和待检验的假设；它希望你复测，而不是照抄。

## 可能不适合谁

- **只想短期提分、背模板、押题的人。** 这里没有考试技巧清单，也不承诺分数。
- **在找成功公式或财富捷径的人。** 作者写的是失败、代价和恢复，不是“如何快速翻身”。
- **正处在急性危机中、需要立即专业照护的人。** 如果你此刻有伤害自己的念头或严重的身体症状，请先联系急救、可信任的人或当地合格的专业支持，再回来读书。本书不能替代照护。
- **想要一套完整英语课程的人。** 英语部分是训练协议和证据卡，不是从音标到写作的系统教材；它假定你愿意自己找材料、做任务、接受反馈。
- **希望书替你做决定的人。** 书里给判断框架和边界，不给“你的人生应该怎样”的答案。

## 写给年轻人

你不必在二十几岁就找到一个永远正确的方向。很多方向不是想清楚之后才出现，而是在做过几个小项目、见过几种工作、承担过几次结果之后，才慢慢从雾里显形。比选中完美赛道更可靠的，是保留学习、交付和转向的能力。

如果职业焦虑让你不停收藏课程、证书和成功故事，不妨换成一个两周可以结束的小项目：解决身边人的一个问题，做出一个能运行的工具，写完一篇有来源的文章，或为真实用户改进一次流程。项目可以失败，但它会告诉你喜欢什么、缺少什么、能否交付，以及别人是否愿意再次使用。

## 写给正在低谷中的人

失业、创业失败、关系结束、健康受损和长时间的迷茫，都会真实地削弱精力。低谷不是一场必须立刻赢下来的考试。今天能做的，也许只是睡一晚相对完整的睡眠、吃一顿饭、走到户外，或向一个可信的人说“我现在需要帮助”。这些事情本身就有意义，不必先把它们包装成一份成长报告。

暂停不是放弃，求助不是软弱，重新校准也不是退步。等力量回来，再决定要不要增加重量。这里的个人故事不是医疗或心理治疗建议；如果低落、失眠、绝望或危险念头持续存在，请联系可信亲友，并寻求当地具备资质的医疗或心理专业支持。先保证安全，再谈成长。
