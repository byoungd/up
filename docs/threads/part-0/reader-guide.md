# 如何读这本书

这不是一本需要从第一页背到最后一页的教材，也不是一份等着你打卡完成的清单。它更像一间可以反复回来的工作室：你带着一个真实问题进来，拿走一个较小的动作，再把结果带回生活。

如果你第一次打开这里，不必先问“我应该读完多少”。先问：**我现在最需要看清什么、完成什么，或停止什么？** 这个问题会替你选择入口。

## 两种读法，轮流使用

### 一条完整的阅读弧线

完整阅读从头读到后记，经历四次变化：

| 阶段 | 阅读范围 | 读完留下什么 |
| --- | --- | --- |
| 接住自己 | [序章](prologue.md) · [我的故事](../part-2/my-story.md) · [恢复篇](../part-2/recovery.md) | 一页可以复查的真实处境：事实、代价、边界和下一步 |
| 重新学习 | [第二部：重新学习，打开输入](../part-1/open-input.md)及其章节 | 一份英语能力基线、一张证据卡和一个可开始的训练周期 |
| 放大与交付 | [第三部：借工具放大能力](../part-3/amplify-ability.md) · [第四部：实践与恢复](../part-4/practice-and-recovery.md) | 一次真实交付、一份来源记录和一个可复测的作品 |
| 交给时间 | [第五部：行动与长期改变](../part-5/long-term-action.md) · [第六部：与自己做终身朋友](../part-6/1-understanding-yourself.md) · [后记](../part-6/afterword.md) | 一份九十天计划、一次周期复盘和一个更稳定的自我关系 |

### 像使用一间工作室一样读

从[阅读地图](../../reference/reading-map.md)、目录或[术语与方法索引](../../reference/glossary.md)直接跳到眼前的卡点。读完一节就暂停，写下一句判断、做一次练习，或保存一份首版样本；过一段时间用[证据链模板](../../templates/evidence-chain.md)和[每周复盘模板](../../templates/weekly-review.md)检查它是否迁移到了新的任务。你不需要记住整本书，只需要让下一次行动更清楚。

这两种读法并不冲突。完整阅读帮助你理解方法为何这样安排，按需阅读帮助方法在今天就产生作用。

## 每一章都留下四种痕迹

读完一个章节，不要只标记“已读”。请至少留下下面四项中的两项：

| 痕迹 | 要回答的问题 | 例子 |
| --- | --- | --- |
| 一个判断 | 我现在比读之前更确定什么？ | “这周只追踪一个主问题。” |
| 一个样本 | 什么输出能证明我做过？ | 一段录音、一封邮件、一张错误清单 |
| 一个边界 | 哪些事不能交给工具或想象？ | 不上传客户隐私；不把单一经历写成规律 |
| 一个回访点 | 什么时候用什么条件复测？ | 七天后换主题重做同一任务 |

如果一章读完只留下了“很有道理”，先不要继续收藏。把它改写成一项可以被别人看见、被自己复查的动作。

## 当计划被打断时，从这里回来

中断不是这套方法的例外，而是它必须能够承受的现实。先打开[学习状态](../../templates/learning-state.md)，标记已经完成、尚未确认、发生的代价和下一步；如果容量发生变化，就回到[最小可行的一天](../part-4/daily-system.md)或[节律账本](../../templates/rhythm-ledger.md)，不要用羞耻把计划重新加重。

等一个可重复的节奏回来，再把任务加回去。真正可靠的系统从来不是不断，而是中断之后仍然知道怎样回家。

## 给读者的一页承诺

在继续下一页之前，你可以写下四句话：

1. 我现在要处理的真实问题是：
2. 我已经拥有的基线证据是：
3. 这次阅读之后，我会在什么时候完成哪一个最小动作：
4. 哪些信息、隐私、健康或关系边界必须由我自己守住：

这四句话足够成为一次开始。读书不是离开生活，读书是让生活重新获得可以被看见的方向。

按具体问题选择入口、准备海外岗位面试、帮助一个初中阶段的学习者，或检查自己是否有真实变化，可以到[阅读地图](../../reference/reading-map.md)查看完整表格。
