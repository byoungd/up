# 版权、版本与引用

这一页记录这本书怎样被命名、授权、引用和更正。它不替代合同或法律意见，只把读者真正需要知道的事情写在明处。

## 版本与书名

当前版本为 **1.1.0**，更新日期 **2026-11-23**。中文书名是《人生进阶指南：一个普通人的失败、恢复与重新学习》；英文书名是 *Still Here: A Field Guide to Beginning Again*。

目录名 `part-1`、`part-2` 等是历史主题标识，不是阅读顺序。书籍的阅读顺序以[本书路线图](roadmap.md)与各页目录为准。

版本号变化时，已发布的中文与英文 EPUB、PDF 会同时重建；文件校验值发布在[下载中心](../../book-downloads.md)，构建清单保存在下载目录里。

## 作者与英文版说明

作者：**韩先凯**。英文版署名 **Han Xiankai**。

中文版是主版本。英文版是独立改写的版本，不是逐字翻译：章节结构、日期与证据对应，但语气、例子和句子长度按英语读者的阅读习惯重写。若两种语言出现理解差异，以中文版的事实与边界为准，并把差异报告给维护者。

「离谱」是作者早期使用的笔名，也是 2017 年那本《离谱的英语学习指南》的来源。它保留在本页和[序章](prologue.md)里作为历史说明，不再作为书名或常规署名；英文版不音译这个笔名。

## 不是医疗建议

书中关于抑郁、焦虑、恢复、睡眠与工作负荷的内容，是个人经验与公开资料的整理，不构成诊断、治疗方案、药物建议或危机干预。恢复篇不提供药物名称、剂量或停药方案，也不提供可能过期的当地热线号码。

如果你正在经历持续的低落、失眠、绝望或伤害自己的念头，请先联系可信任的人，并寻求所在地区具备资质的医疗或心理专业支持。先保证安全，再谈成长。本书不能替代照护。

## 引用与复核

书中的陈述分为三类：**研究结论**、**个人经验**与**待检验的假设**。只有第一类可以直接复述为证据；第二类只证明作者经历过；第三类必须由读者在自己的任务上复测。

AI 产品、模型能力、价格、协议与供应商政策按变化速度分级复核：使用政策、安全公告、产品功能与套餐为 30 天；协议规范与实现指南为 60 天；稳定概念为 120 天。页面里的 `sources_checked` 日期表示外部资料被核验，`updated` 日期表示正文被修改，两者不能互相替代。

完整的来源规则见[资料、引用与核验说明](../../reference/sources-and-citation.md)，条目清单见[参考文献](../../reference/bibliography.md)。

## 勘误与反馈

- 事实错误、失效链接、翻译差异：通过[问题模板](https://github.com/byoungd/up/issues/new/choose)提交，写清页面、原文、来源与建议。
- 安全问题、泄露的个人信息或未经授权的第三方图片：不要公开发布，按 `SECURITY.md` 的私有渠道报告。
- 读者实践回执：可以使用[读者实践回执](../../templates/reader-field-note.md)，但请删除不必要的第三方身份、健康、财务与关系细节。

修订会在下一次发布时进入正文与 EPUB/PDF；历史版本可以通过 Git 提交记录查看。

## 没有出版机构与 ISBN

本书是作者维护的开放书稿，没有通过出版社出版，没有分配 ISBN，也没有纸书发行渠道。EPUB 与 PDF 由本仓库的构建脚本生成，适用于个人阅读与家庭打印，不代表任何出版机构的审校或背书。

引用本书时，请使用书名、作者、版本号、更新日期与网址，并注明正文采用 CC BY-NC 4.0。仓库提供 `CITATION.cff`，便于在支持该格式的工具中直接引用：

```text
韩先凯. 人生进阶指南：一个普通人的失败、恢复与重新学习. 1.1.0 版. 2026-11-23.
https://byoungd.github.io/up/
```

若未来出现正式出版版本，本页会补上出版社、ISBN 与版本对应关系；在那之前，请不要为本书填写任何 ISBN 或出版机构。
