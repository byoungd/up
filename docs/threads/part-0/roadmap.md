# 本书路线图

这本书从一个普通人的失败与恢复写起，再走向重新学习、AI 协作、日常实践和长期行动。它不要求你按顺序走完，但值得先知道整张地图长什么样。

目录名 `part-2`、`part-1` 等是历史主题标识，**不是阅读顺序**。书的顺序以这张表和目录为准：先第一部（故事与恢复），再第二部（重新学习）。

## 三条阅读路径

### 故事优先

适合此刻更想被理解、而不是先学方法的人。

1. [序章](prologue.md) → [我的故事](../part-2/my-story.md)；
2. [我还在这里](../part-2/depression-anxiety-recovery.md) → [恢复篇](../part-2/recovery.md)；
3. [选择篇](../part-2/decision.md) → [关系篇](../part-2/relationships.md)；
4. 有余力时再进入[第二部导语](../part-1/open-input.md)。

### 方法优先

适合带着一个具体任务来、想尽快开始的人。

1. [CEFR 自测](../part-1/0-cefr.md) → [认知与训练原则](../part-1/1-understanding.md)；
2. 在词汇、语法、听、读、说、写中选**一条**主线，做完一次十四天实验；
3. [使用 AI 学习一切](../part-3/1-ai-learning.md) → [作品篇](../part-3/4-artifacts-and-delivery.md)；
4. [第一周实践](../part-4/week-1.md) → [九十天行动篇](../part-5/90-day-plan.md)。

### 容量很小的时候

适合身体或情绪状态不允许长时间阅读的人。

1. 只读[恢复篇](../part-2/recovery.md)里“降低负荷”的一节，不做练习；
2. 打开[学习状态模板](../../templates/learning-state.md)，只写四行：问题、线索、最小动作、边界；
3. 今天到此为止。把[节律账本](../../templates/rhythm-ledger.md)放到明天或下周，不补作业。

三条路径可以中途交换。读故事读到想做事，就转到方法；做方法做到无力，就回到恢复。书的结构允许往返。

## 今天只有五分钟

如果你现在只有一个很小的空档，不要试图开始一部书：

1. 打开[学习状态模板](../../templates/learning-state.md)；
2. 写下你眼前最真实的一个问题；
3. 写下一个**今天能完成**的最小动作；
4. 写下一个必须守住的边界（隐私、身体、关系或金钱）。

这四行就是一次开始。五分钟不需要产出结论，只需要把下一步从雾里拿出来。

## 读完以后

正文之后是附录，按用途排列：先查[术语与方法索引](../../reference/glossary.md)，再按问题进入[阅读地图](../../reference/reading-map.md)；需要动手时打开[工具箱总览](../../templates/toolkit.md)；想引用或核对来源时看[参考文献](../../reference/bibliography.md)与[资料、引用与核验说明](../../reference/sources-and-citation.md)；想了解这本书是怎样被做出来的，可以读附录里的[本书案例](../part-5/book-as-proof.md)。

如果你读完了，最值得留下的不是“我读完了”，而是一次真实交付、一份复测记录，或一个愿意在九十天后回来检查的决定。把它们放进[九十日行动总表](../../templates/90-day-cycle.md)。
