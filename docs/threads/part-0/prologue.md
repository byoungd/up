# 序章：先不要急着改变人生

作者：韩先凯（曾用笔名：离谱）

2022 年深秋，我在一家火锅店里刷不出那一顿饭的钱。

卡被冻住了。手机屏幕亮着，余额不足的提示躺在那里，像一句迟到的判决。我对面的朋友还在说话，锅里翻着红油，店里很吵，我却只听见自己的心跳。那一刻我才承认，公司的现金流已经断了，而我一直以为“再撑一下”就能撑过去的事，终于没有撑过去。

更早之前，身体先发出了信号。失眠、心悸、突然冒出的冷汗，凌晨两点还坐在空办公室的椅子上，盯着没有因为我的坚持而变好的数字。后来是关系。人在下坠的时候，很难同时照顾好别人；有些话说出口，就再也回不到原来的位置。

再后来，我收拾行李，回到老家，住进一间小时候住过的房间。窗帘旧了，书桌还在，窗外是我十几岁时看过的那条路。那年我三十多岁，失败得并不体面，也没有任何一句励志的话可以立刻用上。我能做的只有几件很小的事：按时吃饭，去看医生，睡一个相对完整的觉，把欠下的话一句一句说清楚。

这就是这本书真正的起点。

## 2017 年的那个问题

2017 年 7 月，朋友 `W.` 正在准备托福。她问我：“怎样才能高效地学好英语？”

那时我以为，这只是一个关于词汇、语法和学习方法的问题。于是我把自己走过的弯路写下来：怎样背单词，怎样练听力，怎样让一本原版书不再像一堵墙，怎样在不敢开口的时候先说出第一句不完美的英语。

后来我才发现，她真正问的或许是另一件事：**一个普通人，怎样在有限的时间、反复的挫败和并不理想的生活里，仍然把自己往前带一点？**

我用了很多年，才听懂这个问题。英语是一扇具体的门：你可以用它读一篇没有翻译的文章，听懂一段工作会议，给远方的人写信，在信息混乱的时候多一个角度。但门打开之后，要面对的仍然是自己——怎样安排时间，怎样对待身体，怎样承受失败，怎样把一个念头变成作品，怎样在失去一些东西之后，继续照顾眼前的人。

我曾经把人生想象成一条不断升级的游戏路线：完成一个目标，就获得下一件装备；赚到足够的钱，就拥有稳定的幸福；做出一个产品，就证明过去的选择没有错。后来公司倒闭，身体失去控制，关系和自尊一起跌到谷底，我才明白，人生更像一间每天都要重新整理的房间。昨天留下的灰尘今天还在；一件坏掉的家具，不能靠更响亮的口号修好；窗外的天气，也从来不听我们的安排。所谓进阶，很多时候只是把地面扫干净，把该道歉的话说出来，把身体送去看医生，把今天能完成的那一步完成。

## 这本书会给你什么

所以，这不是一本承诺你“变得厉害”的书。它只想提供四样东西，顺序按我需要它们的先后排列：

1. **一套先把自己接住的办法**：安全、睡眠、求助、把羞耻还原成事实，以及在容量很小的时候，允许自己只完成最小的一步；
2. **一条可执行的英语学习路径**：让输入、输出、反馈和复习形成循环，让英语成为重新进入世界的第一个训练场；
3. **一套与 AI 协作的学习方法**：让工具帮助你长出判断力，而不是替你逃避思考，也不把来源、隐私和责任一起外包；
4. **一份九十天的行动方案与一组真实记录**：让读过的内容有机会变成作品、反馈和新的生活节奏，也让个人经历接受证据的检验。

## 怎样读这本书

你不必从第一页读到最后一页。如果你正处在低谷，先读[我的故事](../part-2/my-story.md)和[恢复篇](../part-2/recovery.md)，今天的目标可以只是安全地过完这一天；如果你已经稳住了，想重新开始学习，从[第二部：重新学习，打开输入](../part-1/open-input.md)进入；如果你有很多资料却没有作品，先看[使用 AI 学习一切](../part-3/1-ai-learning.md)和[九十天行动篇](../part-5/90-day-plan.md)。

完整的阅读路线、按问题进入的入口和每一章可以留下的痕迹，都放在[如何读这本书](reader-guide.md)和附录的[阅读地图](../../reference/reading-map.md)里。这一页只负责把你带进门口。

请把每一章当成一张工作台，而不是一场考试。读完后只带走一件事：一个句子、一项练习、一个需要停止的习惯，或者一个准备重新开始的念头。知识如果没有在生活里留下痕迹，就还只是漂亮的路标。

## 写给此刻翻开这本书的人

也许你正坐在通勤的地铁里，手机屏幕上堆满收藏；也许你刚结束一段关系，正在想自己是不是从此只能停在这里；也许你被工作、债务、考试或病痛推到墙角，连“努力”两个字听起来都觉得疲惫。

我没有资格替你保证明天会变好。我能说的只有：人的生活通常不是被一次巨大的胜利拯救的，而是被许多细小、重复、没人鼓掌的动作慢慢托住的。

今天记住五个词，明天听十分钟真实英语，后天写一段不求漂亮的文字；把一件拖了很久的小事做完，给一个应该道歉的人发消息，按时吃饭，早点关灯。它们看上去彼此无关，却会共同构成一种新的证据：**我仍然能够对自己的生活施加一点影响。**

这点影响不必宏大，但必须真实。

愿你从这里开始，不是为了成为另一个人，而是为了更完整地成为自己。
